# Paper dependency maps

The maps organize each paper's named results into sections. Expanding a section reveals the individual results and their formalization status. Selecting a result in the interactive viewer shows what it uses, what uses it, and links to the relevant Lean certificates.

- [Strong existence and uniqueness of the tilt-indexed Busemann process in the planar corner growth model](https://cjanjigi.github.io/LPP/?paper=strong-existence) · [Static map and coverage notes](paper-results/strong-existence.md)
- [Differentiability of the shape function in the planar corner growth model](https://cjanjigi.github.io/LPP/?paper=differentiability) · [Static map and coverage notes](paper-results/differentiability.md)
- [Limiting shape for directed percolation models](https://cjanjigi.github.io/LPP/?paper=martin-2004) · [Static map and coverage notes](paper-results/martin-2004.md)
- [Inequalities with applications to percolation and reliability](https://cjanjigi.github.io/LPP/?paper=bk-1985) · [Static map and coverage notes](paper-results/bk-1985.md)
- [An improved subadditive ergodic theorem](https://cjanjigi.github.io/LPP/?paper=liggett-1985) · [Static map and coverage notes](paper-results/liggett-1985.md)

The interactive links open the public viewer; the static links open GitHub-readable diagrams, progress lists and coverage notes. Both presentations use the same result records. See the [graph instructions](../README.md#interactive-graphs) for local preview.

Dependencies come from the paper's proofs. Certificate links and scope are assessed separately against the revisions linked in each guide. A certificate's inclusion of several conclusions does not create a dependency in the paper. Related formulations and proof adaptations are recorded separately from prerequisites. Results whose certificate correspondence has not been checked are marked **Not assessed**.

Source versions are identified in each guide. Public graph records identify named results and printed pages where available; source papers, manuscript files and development records are not included.
